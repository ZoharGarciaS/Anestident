# AnestiDent — web de presentación

Sitio estático independiente del firmware ESP32. Diseño original con HTML, CSS, JavaScript y modelos tridimensionales paramétricos renderizados mediante WebGL nativo. No usa IA generativa en ejecución, CDN, servicios externos ni dependencias de instalación.

## Alcance

Modelos 3D conceptuales, no escaneos clínicos. Ubicación de marcadores aproximada; validar con el tipodonto físico y docente. El sitio no comunica con el ESP32, no recoge datos personales y no evalúa destreza clínica. La demostración usa una secuencia ilustrativa y la fórmula 1 + 9 × cobertura × precisión. El firmware del prototipo se conserva por separado. No se incluyen credenciales Wi-Fi ni IP privadas.
